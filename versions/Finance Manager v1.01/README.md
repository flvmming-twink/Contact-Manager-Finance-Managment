# Finance Manager v1.01

Первая версия нового финансового направления проекта.

## Реализовано

- локальная SQLite-модель пользователей, категорий, операций и бюджетов;
- CRUD для операций, категорий и месячных бюджетов;
- панель итогов выбранного месяца;
- аналитика расходов по категориям и динамики баланса;
- предупреждения при расходовании 80% бюджета и при превышении лимита;
- фильтры и CSV-экспорт;
- русскоязычная Material 3-тема, светлая и тёмная палитры;
- версия приложения `1.01` (`versionCode 101`).

APK хранится в корневой папке `apps` под именем `FinanceManager-v1.01-debug.apk`.
